# Request for Comments (RFCs)

The RFC process is the formal mechanism for proposing, reviewing, and reaching consensus on substantial changes to the `ai-native-runtime` architecture, APIs, network protocols, and execution models.

## Workflow States
- `rfcs/proposed/`: RFCs currently open for public review and feedback.
  - [`RFC-0001`](proposed/0001-declarative-task-graph.md): Declarative Task Graph and Zero-Copy Task Descriptor Protocol.
- `rfcs/accepted/`: RFCs that have reached technical consensus and are scheduled for implementation.
- `rfcs/rejected/`: RFCs that were considered but rejected with documented rationales.
- `rfcs/withdrawn/`: RFCs withdrawn by the author.

## Proposing an RFC
1. Copy [`rfcs/template.md`](file:///a:/master_project/rfcs/template.md).
2. Name the file `YYYY-MM-DD-short-title.md` under `rfcs/proposed/`.
3. Submit a Pull Request.
4. Discussion occurs publicly in the PR and community discussions.
